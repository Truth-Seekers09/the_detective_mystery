DETECTIVE MYSTERY: THE HIDDEN TRUTH
Team Truth Seekers (T152), Graphic Era Deemed to be University, Dehradun

HOW TO PLAY
1. Unzip this folder anywhere (do not run it from inside the zip).
2. Double-click "Play Detective Mystery.vbs". (If nothing opens, use "Play (show errors).bat".)
3. The game opens in its own window. Close the window to quit.

If Windows SmartScreen or your antivirus warns about the program, it is because the game is new and not
digitally signed. It only runs on your own computer (127.0.0.1) and does not use the internet.
Choose "More info" -> "Run anyway", or allow it in your antivirus.

CONTROLS  A/D or arrows walk | Shift run | W/S depth | E interact | F search | J evidence | U suspects | H hint | M map | X accuse
